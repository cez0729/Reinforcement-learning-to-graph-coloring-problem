# Paper sources

The main LNCS source is `src/main_lncs_blind.tex`. Compile it with `paper/src` as the working directory and keep the repository-relative `../figures`, `../tables`, and `../supplementary` directories in place.

The other entry files are provided for the corresponding IEEE or camera-ready layouts. The generated PDFs are reference artifacts; the `.tex` sources are the editable files.
